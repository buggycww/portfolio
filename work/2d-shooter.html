github.com/buggycww/2D-Shooter

A 2D action platformer built from scratch in C++17 and SDL3. No engine, no shortcuts.

Everything is hand-written: the game loop, input, rendering, audio, asset loading, and collision. Levels are TMX files, so a level is data rather than code.

Movement resolves one axis at a time, actors first and level geometry second, so the player cannot be pushed through a wall. A quadtree keeps collision from testing every object against every tile.

Features

  • AABB collision with per-axis resolution
  • Quadtree broad phase — only the boxes near the player are tested
  • TMX tilemaps loaded with tinyxml2
  • Animation states and parallax backgrounds
  • Debug overlay with frame time and quadtree stats
  • Audio, asset loading, and a fixed-timestep loop
