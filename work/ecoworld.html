EcoWorld

A mixed-reality ecology game for Meta Quest 3. Build an ecosystem on a table, change the weather, and see what happens.

Role
Solo design & programming
Engine
Unity
Platform
Meta Quest 3
Year
2026
Award
National 2nd Runner-Up

EcoWorld was my final-year project. It is a game about how a small change in an ecosystem can affect everything else.

What I did

  • Built the game in Unity for Meta Quest 3.
  • Wrote a state machine for organism behaviour. Animals react to food, safety, and the environment.
  • Built time-of-day and weather systems that change the conditions organisms live in.
  • Added disaster events that stress the ecosystem and force the player to respond.
  • Ran playtests and changed what the game shows based on what players noticed.

How it works

The game is split into three parts: organisms, environment, and events. Organisms choose what to do from their needs and the current conditions. Weather and disasters change those conditions, which changes what organisms do next. The player can change one variable and watch the results.

Result

Second Runner-Up at Malaysia Creative Tech Competition 2026, selected from 87 entries across 23 institutions.

What I would improve

Better onboarding: teach the cause and effect before asking the player to optimise it. I would also set a clearer performance budget for each scene.
