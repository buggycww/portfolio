Everything is Against You

Role
Solo · design, code, art
Engine
Unity
Platform
Browser (HTML5)
Jam
Brackeys Game Jam 2026.2
Year
2026

A tiny 2D game where everything is out to get you. Be warned.

How long can you survive when everything is against you? Every trap is placed to punish the obvious path, and the obvious path is the only one you see the first time.

Made solo for Brackeys Game Jam 2026.2, from an empty project to something you can finish in one sitting. It runs in the browser, so there is nothing to install.

Features

  • Trap triggers that fire the moment you commit
  • Interaction prompts — press, hold, or walk away
  • Dialogue that knows what you just did
  • Checkpoints, so the traps stay funny
  • Top-down pixel art, one screen at a time
  • Playable in the browser
