Rush-Cavate is a 3D Bomberman-style game inside Genshin Impact's Miliastra Wonderland. I worked on it as a game programming intern at Virtuos Kuala Lumpur.

What I did

  • Implemented elemental bombs: placement, behaviour, and interactions between bomb types.
  • Worked on upgrade paths that change how the core bomb loop plays.
  • Built grid placement, movement, and range indicators.
  • Implemented skills and the tutorial.

How I worked

The project was inside a large existing codebase. I read the surrounding code first, found the right places to add code, and kept the first version small enough to test. I worked with designers and engineers through daily stand-ups and playtests, and changed priorities based on what players actually understood.

What I learned

A range indicator can look correct in the editor and still be unreadable in play. The same was true for the tutorial: it had to teach the loop in the same language the player experiences it. I also learned to keep the code separated enough to change it later.
